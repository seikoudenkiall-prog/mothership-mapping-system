# マザーシップ型立体マッピングシステム (mothership-mapping-system)

## プロジェクト概要
親機（マザーシップ）と子機（エクスプローラー群）の協調により、複雑な凹凸障害物環境を高精度かつ低コストで3Dマッピングする自律システム。

## ターゲット環境・制約仕様
- **対象敷地**: 2,000 ㎡ 以下
- **構造物高さ**: 2.0 m 以内（トラス、低背配管、機器基礎、突起物等）
- **精度目標**: 水平位置（XY）および高さ（Z）ともに **30 mm（3 cm）以下**
- **ハードウェア構成**:
  - 親機: 見下ろし高度 3.5 m、大域トラッキングセンサ、iSAM2最適化ハブ
  - 子機: 小型準ソリッドLiDAR / 近接RGB-D、パルス変調アクティブLEDマーカー
- **新規コア技術**:
  1. 2m天井境界を利用した「鉛直ホッピング（一時浮上）即時再同期」
  2. 累積共分散リミット（30mm保証）付きテザー型 Active NBV 自律経路計画
  3. 粗疎親機点群をアンカーとする階層型TSDFボクセル統合
